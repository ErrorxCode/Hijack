## ✨ Main Features
- **Bypass screen recording** - You can stop the screen recording and they won't know!.
- **Spoof entire screen** - You can select any screen while sharing screen to website, and it will work!
- **Allows Tab/Window switch** - You can easily switch between tabs and windows
- **Allows copy/paste** - Now copy/paste easily on any restricted site
- **Auto right click** - Unblocks right click on restricted websites
- **On/off switch** - Easily turn on/off for particular sites in one click

## ℹ️ How to install?
1. Firstly, download and extract the extension zip from the latest release (or the above button)
2. Go to `chrome://extentions`, enable *Developer mode* from the top right.
3. Click on the *Load unpack* button and select the extracted extension folder.
4. The extension is now installed. Now you can activate the extension for any site by clicking on the extension icon



## 🧑‍💻 Usage
On the site on which you want to tab/switch or copy/paste etc or spoof/bypass screen recording, just click on the extension icon to turn it on or off for that particular website
